# LeadCut 0.1.3 发布记录

2026 年 11 月 25 日发布 Windows x64 安装版。

## 本版改动

- **Agent 协作**。应用设置可以连接 Codex 或 Claude Code，安装包内置 MCP。编辑器可以交接工程并进入只读，随后自动加载磁盘上的新版本。合并收到多次写入时，复核面板会区分剪切带来的自动位移和主动编辑的字幕、缩放及章节。用户可以接受、撤回适用的变更，并导出交接备注。
- **编辑器和字幕**。减少播放、时间线和字幕面板的重复渲染。字幕测宽在空闲时分批准备，改颜色时复用排版。外观滑块一次拖动只记一笔撤销，旧工程外观和新录制的默认外观可以分别保存。
- **录制和恢复**。统一录制、保存、恢复、识别与导出的任务提示。改善 Windows 录制收尾、摄像头延迟配对，以及录制中断后的恢复。字幕识别支持进度、取消、检查点续跑和模型下载校验。
- **导出**。改善多轨素材解码、混音、封装和取消后的资源清理。Windows 打包版包含共享媒体运行库和 Whisper，保留 WebCodecs、Breeze 与兼容导出路径。
- **工程和安装**。加强工程写入锁、修订冲突与本地媒体访问检查。安装包压缩内置壁纸并合并重复运行库，包含版本检查所需的更新清单和差量文件。

## 验收范围

同源候选版在 Windows 和 Ubuntu WSL2 各通过 1,921 项单测，各有 7 项按环境跳过。Windows 打包 MCP 的 38 项检查与 15 项相关界面回归通过。实包通过真实 MCP 写入，验证了只收到最终通知或直接恢复编辑时，选择性撤回字幕和章节仍能保留已接受的剪切、缩放和自动位移。Ubuntu WSL2 验证了 H.264 导出、窗口录制及 Whisper 识别。

Windows 安装包未签名。个别外观与字号拖动帧、4K60 故障回退和连续取消后的显存仍超过原评审的性能预算。不同硬件组合、macOS 和 Linux 物理桌面的完整测试仍待验收。
